# Quantum Entanglement & Measurement Simulator (Bell State)

This project simulates a 2-qubit quantum system using NumPy.

## Features
Bell state generation using Hadamard and CNOT gates
Measurement probability calculation (Born rule)
Quantum measurement simulation
State collapse modeling
Repeated trials to validate probabilistic outcomes

## Languages used
Python
NumPy

## Output
Demonstrates entanglement between qubits
Shows correlated measurement results
